# USTINOVA NAIL STUDIO — сайт студии

Одностраничный сайт ногтевой студии Ольги Устиновой (г. Боровск, пл. Ленина, 27).

Открывается на любом телефоне и компьютере. Интернет нужен только для перехода по ссылкам
(запись, звонок, карты) — сама страница работает автономно.

---

## Как посмотреть

Просто откройте `index.html` в браузере. Никакой установки, сервера и настроек не требуется.

## Как опубликовать (GitHub Pages)

1. Создайте репозиторий на github.com (лучше приватный или публичный — на ваш выбор).
2. Через кнопку **Add file → Upload files** загрузите сюда **всё содержимое этой папки**:
   - `index.html`
   - папку `images` целиком (все 11 файлов)
3. Откройте **Settings → Pages**.
4. В разделе *Build and deployment* выберите **Deploy from a branch**, ветка `main`,
   папка `/ (root)` → **Save**.
5. Через минуту сайт откроется по адресу `https://<ваш-логин>.github.io/<название-репозитория>/`.

### Свой домен

1. Создайте в корне репозитория файл `CNAME` (без расширения) и впишите в него домен,
   например `olgustinova.ru`.
2. Затем **Settings → Pages → Custom domain** — укажите тот же домен и сохраните.
3. В панели регистратора домена добавьте DNS-записи, которые покажет GitHub
   (обычно CNAME на `username.github.io` и четыре записи A).
4. Включите **Enforce HTTPS**, когда GitHub их подтвердит (обычно 15–30 минут).

После этого сайт будет открываться по обычному адресу без `github.io`.

## Как заменить фотографии

Положите свои файлы в папку `images`, сохранив те же имена — и всё. Больше ничего менять не нужно:

| файл | что на фото |
|---|---|
| `work-manicure.webp` | до/после — комби-маникюр |
| `work-pedicure_pink.webp` | до/после — педикюр |
| `work-nail.webp` | до/после — ноготь крупным планом |
| `work-nail_care.webp` | до/после — восстановление |
| `service-nails.webp` | фото для вкладки «Маникюр» |
| `service-pedicure.webp` | фото для вкладки «Педикюр» |
| `service-extension.webp` | фото для вкладки «Дополнительно» |
| `process.webp` | фото «Как проходит работа» |
| `hero.webp` | фоновая заставка (видео перекрывает её) |
| `hero-poster.webp` | кадр-постер, пока грузится видео |
| `hero-loop.mp4` | видео на главном экране, 8 секунд по кругу |

Чтобы убрать или добавить работу в блоке «До и после», откройте `index.html`,
найдите `<figure class="ba-slide" ...>` — один такой блок = одна работа. Скопируйте
или удалите целиком, поправите `animation-delay` по порядку: `0s`, `6s`, `12s`, `14s`…

## Технически

- Чистый HTML + CSS. **JavaScript не используется** — вкладки услуг работают на CSS,
  вопрос-ответ на нативном `<details>`. Поэтому ничего не сломается, если что-то не
  догрузилось.
- Страница лёгкая: `index.html` около 56 КБ, картинки и видео — отдельными файлами.
- Ролик `hero-loop.mp4`: 8 секунд, 854×480, 263 КБ, без звука — чтобы не мешал
  и быстро грузился на мобильном интернете.
- Работает от 320 px ширины, горизонтальной прокрутки нет.
