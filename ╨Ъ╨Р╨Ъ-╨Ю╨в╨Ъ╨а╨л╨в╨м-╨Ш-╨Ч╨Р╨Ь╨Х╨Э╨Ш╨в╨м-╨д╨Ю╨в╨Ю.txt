• Вкладки услуг и FAQ работают БЕЗ JavaScript (сделано на CSS и
  нативном <details>) — на медленном мобильном интернете ничего не

• Файл открывается офлайн; внешние зависимости — только шрифты Google
  (если их не загрузилось, подставятся системные засечки — вид нормальный).
• Превью в мессенджерах (og:image) работает, когда сайт выложен
  по ссылке; при отправке самого файла превью покажут картинку из файла.

КАК ПОМЕНЯТЬ ФОТО НА СВОИ
-------------------------
1. Скопируй к себе папку с файлами, например
   C:\Users\User\Desktop\сайт-устиновой.
2. Положи туда свои фотографии и переименуй:
     hero.jpg              — запасной фон первого экрана (если кадры не загрузятся)
     hero-frame-1..4.webp  — кадры видео-подложки в главной
     work-*.webp           — работы «до/после» (по одной на каждую)
     service-nails.jpg     — маникюр
     service-pedicure.jpg  — педикюр
     service-extension.jpg — наращивание
     gallery-1.jpg … gallery-8.jpg — работы (8 покрытий)
     process.jpg           — процесс работы мастера (широкая полоса)
   Расширение любое: .jpg, .jpeg, .png, .webp.
3. Запусти:
       python вставить-свои-фото.py "C:\Users\User\Desktop\сайт-устиновой"
   (если ругается на Pillow: pip install pillow)
4. Рядом появится готовый index.html с твоими фото внутри.
